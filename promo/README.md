# 知我 SELF NOTE · 宣传海报

恋爱依恋 / 星座星语 分开出品，可直接发小红书与闲鱼。

## 文件

| 文件 | 用途 | 尺寸 |
|---|---|---|
| `love-xhs.png` | 恋爱 · 小红书封面 | 1080×1440（3:4） |
| `zodiac-xhs.png` | 星座 · 小红书封面 | 1080×1440（3:4） |
| `love-xianyu.png` | 恋爱 · 闲鱼主图 | 1080×1080（1:1） |
| `zodiac-xianyu.png` | 星座 · 闲鱼主图 | 1080×1080（1:1） |

同名 `.svg` 为可编辑源文件。

## 重新导出

```bash
node promo/build-svgs.mjs
node promo/render.mjs
```

## 发布建议

- 小红书：竖版当封面；正文可写「3 分钟 / 不登录 / 本机隐私 / 仅供娱乐」
- 闲鱼：方图当主图；标题示例「知我恋爱依恋测试｜本机结果卡」或「知我星座星语｜日月升简版」
- 两条线建议分开发帖，避免一张图塞两个主题
